# prueba_hlf
## 𓇼⊹ ࣪ ﹏𓊝﹏𓂁﹏⊹ ࣪ ˖𓇼 Hundir la flota 𓇼 ⋆.˚ 𓆉 𓆝 𓆡⋆.˚ 𓇼

Proyecto desarrollado en Python para el bootcamp de Data Science con IA. Consiste en una versión del juego **Hundir la flota** para jugar contra la máquina desde la terminal.

Cada jugador dispone de un tablero de ***10 × 10*** casillas y una flota de ***6*** barcos:

- ***3 barcos de 2 casillas 𓊝***.
- ***2 barcos de 3 casillas ⚓︎***.
- ***1 barco de 4 casillas ⛴***.

Los barcos se colocan aleatoriamente en horizontal o vertical, evitando que se superpongan o salgan del tablero. Durante la partida, el jugador y la máquina se turnan para disparar hasta que uno de los dos consiga hundir toda la flota rival.

## ⌯⌲ Archivos del proyecto

- ***`main.py`***: controla la partida y los turnos.
- ***`utils.py`***: contiene las funciones principales del juego.
- ***`pruebas.py`***: permite comprobar que las funciones funcionan correctamente.

## ✎ᝰ.ᐟ Objetivo del proyecto

Llevar el clásico **Hundir la flota** al mundo de Python, combinando lógica, estrategia y aleatoriedad para crear un juego interactivo desde cero y poner en práctica lo aprendido en el bootcamp con el mejor profesor **(｡˃ ᵕ ˂ ) Diego Nuñez (*ᴗ͈ˬᴗ͈)*.ﾟ**.
